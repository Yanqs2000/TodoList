# v0.1.2 — 日历时间选择器（2026-06-12）

## 新功能

### 📅 日历时间选择器

替换原生 `<input type="datetime-local">` 为自定义组件：

- **月视图日历**：可前后翻月，今日高亮，选中态明显
- **时间滚动选择器**：小时（0-23）和分钟（0-59）双列滚轮，点击选择
- **时间点 / 时间段模式**：支持单点时间或起止时间段
- **青绿色主题**：匹配应用整体配色

### 🎨 UI 改进

- 修复日历网格对齐问题（用 `grid-column` 精确定位）
- 修复删除按钮图标缺失
- 优化优先级标签颜色：低=绿、中=黄、高=红
- 增强任务卡片阴影效果（双层 shadow）

## 文件变更

- 新增 `src/components/TimePicker.tsx` + `src/styles/TimePicker.css`
- `TaskInput.tsx` 集成 TimePicker，显示时间预览
- `TaskItem.tsx` 显示任务时间标签
