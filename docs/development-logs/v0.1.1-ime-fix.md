# v0.1.1 — 输入法修复（2026-06-11）

## Bug 修复

### 中文输入法 Enter 键误提交

**问题**：在使用中文输入法（IME）输入拼音时，按 Enter 选择候选词会被误判为提交任务，导致任务文本不完整就被提交。

**修复**：在 `TaskInput` 中追踪 `isComposing` 状态，监听 `compositionstart` / `compositionend` 事件。只有当 `!isComposing` 时才响应 Enter 提交。

```typescript
const handleKeyDown = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter' && !isComposingRef.current) {
    handleSubmit();
  }
};
```
