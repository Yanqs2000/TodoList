# v0.5.0 — 聚焦时间轴 Today Focus（2026-06-23）

## 背景

待办应用的首页主角应是「现在该做什么」，而非 backlog 倾倒。此前列表把所有任务摊成等高条目，时间信息缩成一个小 tag，应用的时间感知能力（提醒、时间字段、按时间排序）没有在视觉上体现。

本版把列表从「按分类平铺」改成「按时间聚焦」：顶部加一条横向今日时间轴作为视觉主角，并按时间临近度分组与上色。

## 新增能力

### 📅 今日时间轴（DayTimeline）
列表顶部横向时间轴（06:00–24:00 工作窗）：
- 有时间的今日任务画成色块落在对应时刻，宽度 = 任务时长
- 一根 `now` 指示线随系统时间移动（每分钟更新，1s 平滑过渡）
- 未设定时间的任务收成右端「待安排 (N)」簇
- 今天无计划任务时显示空态提示
- 点击色块 → 选中任务（与列表/详情联动）

### 🎨 时间临近色条（TaskItem）
任务卡左缘 3px 色条按临近度上色：
- 已过期 → 红 `--time-overdue`
- 1 小时内 → 琥珀 `--time-soon`
- 今天稍晚 → 主题色 `--primary`
- 未来 / 无时间 / 已完成 → 不画

### 🗂 按时间分组（active + 按时间排序）
切换到「进行中」+「按时间排序」时，列表按临近度分四组：
**已过期 / 今天 / 以后 / 待安排**，每组带计数与色点。

## 设计决策

- **时间轴只显示「今日」任务**：`isToday` 过滤，避免昨天的 15:00 任务被错误放到今天 15:00 位置（`toTimelineX` 只看小时，跨日会错位）。跨日任务只在「已过期/以后」分组里出现。
- **单一时间源**：`TaskList` 持有 `now`（60s 节流刷新），下发给 DayTimeline / 分组 / 色条，避免多份时钟漂移。
- **不改状态层**：未碰 `useTodos`、localStorage、任何 hook 签名。时间轴与分组叠加在已过滤的 `todoState.tasks` 之上。
- **默认视图即亮主角**：active + manual 也渲染时间轴；切「按时间排序」叠加分组。未改默认 sortMode，行为兼容。
- **`now` 可注入**：DayTimeline / TaskList 接受可选 `now` prop，便于确定性单测（生产走实时）。

## 纯函数 lib：`timeProximity.ts`

| 函数 | 说明 |
|---|---|
| `proximityOf(time, now)` | `'overdue' \| 'soon' \| 'today' \| 'future' \| 'none'` |
| `isToday(iso, now)` | 同日历日 |
| `toTimelineX(iso)` | 06–24 映射为 0–100%，<06 钳到 0 |
| `parseTimeStart(iso)` | 本地 ISO → epoch，复用 useReminders 约定 |

全部纯函数、`now` 由调用方传入，可单测。

## 边界处理（已验证）

1. 今天无定时任务 → 轨道空态提示
2. 今日过期任务 → 色块在实际过去位置、红色（非全钳左端）
3. 06:00 前 → 钳到 0%
4. 跨日 range（start 今日 / end 明日）→ 块宽截到 24:00 右端
5. 未来日期任务 → 不上今日时间轴（仅进「以后」分组）
6. 无 time 任务 → 只进「待安排」
7. 完成视图（filter=completed）→ 时间轴不渲染
8. now 在 06–24 窗外 → now 线隐藏
9. 选中态 → 时间轴色块与列表卡片联动高亮
- <720px → 横向时间轴隐藏，分组保留
