# v0.2.0 — 三栏布局重构 + 6 主题系统（2026-06-17）

## 概览

v0.2.0 是一次重大 UI 重构。从 640px 居中单列布局，重构为 1080px 三栏工作台布局（Sidebar + List + Detail），并引入 6 套主题系统（3 风格 × 2 明暗）。

## 11 项设计决策

| # | 决策 | 选择 |
|---|------|------|
| 1 | 布局 | 三栏（Sidebar 240px + List + Detail 320px） |
| 2 | 主色 | Teal（浅色 #0D9488 / 深色 #2DD4BF） |
| 3 | 字体 | Inter + 系统中文（PingFang SC / Microsoft YaHei） |
| 4 | tag 视觉 | 透明 + 边框 + 彩色字 |
| 5 | 进度环/统计 | Footer 三卡片网格 |
| 6 | 任务卡密度 | 双行（主行：checkbox+text+time+actions；次行：priority+category+notes） |
| 7 | 创建任务入口 | 顶栏按钮 + Cmd+N + 模态 |
| 8 | Sidebar | 5 分类入口 + 状态过滤 + 底部迷你进度环 |
| 9 | 详情面板 | 选中详情 / 未选今日摘要 |
| 10 | 浅色 vs 深色 | 浅色为主（默认 workspace-light） |
| 11 | 主题系统 | 6 套（3 风格 × 2 明暗），弹层 popover 选择 |

## 6 主题清单

| ID | 名称 | bg | 风格定位 |
|---|---|---|---|
| `workspace-light` | 工作台 · 浅 | #FAFAF7 | 暖白，日常办公（默认） |
| `editor-light` | 编辑器 · 浅 | #FFFFFF | 冷白，VSCode 风 |
| `paper-light` | 纸笺 · 浅 | #F7F6F3 | 米色纸感，Notion / Bear 风 |
| `workspace-dark` | 工作台 · 深 | #0E0E10 | 深色暖灰 |
| `editor-dark` | 编辑器 · 深 | #0E0E10 | 深色冷灰 |
| `paper-dark` | 纸笺 · 深 | #0E0E10 | 深色纸感 |

所有主题统一使用 teal 主色与深色 bg #0E0E10，但 card-bg、text、border 等 token 各自调整以营造不同质感。

## 主题 tokens 设计

每套主题包含 24 个 CSS 变量：
- **色板**：primary, primary-light, primary-soft, cta
- **背景层级**：bg, bg-elevated, card-bg, card-bg-hover
- **文本层级**：text, text-muted, text-light
- **边框**：border, border-strong
- **状态**：danger, danger-hover, active-bg
- **优先级**：priority-high / medium / low
- **阴影**：shadow-sm / md / lg
- **圆角**：radius / radius-sm / radius-lg
- **过渡**：transition, completed-opacity

## 主要交互改进

1. **任务选中态** — 点击任务卡左侧/中央高亮选中并在 Detail 显示详情；再点取消选中切换到今日摘要
2. **Cmd+N / Ctrl+N** — 全局快捷键，任意时刻打开创建任务模态
3. **主题切换 popover** — 点击右上角主题按钮，6 卡片网格选择，选中即生效
4. **响应式降级**：
   - ≥ 1024px：完整三栏
   - 720–1024px：隐藏 Detail，保留 Sidebar + List
   - < 720px：仅 List（隐藏 Sidebar 和 Detail）
5. **迷你进度环** — Sidebar 底部固定，48×48 SVG，实时反映今日完成进度

## 测试与构建

- 52 个单元测试通过（v0.1.5 时 48 个，新增 4 个 useTheme 测试覆盖 6 主题与 legacy 迁移）
- TypeScript strict 模式无报错
- Vite 构建产物 245.86 kB JS / 42.05 kB CSS（gzip: 75.49 kB / 6.94 kB）
- Tauri 窗口默认尺寸 1080×720（最小 720×560）

## 不在本轮的事项

- ConfettiCanvas 在新布局下的爆发位置仍以视口为基准（已验证可用）
- AchievementDrawer 暂未做 focus trap
- 暗色主题下任务卡 priority-tag 的对比度已通过 `color-mix` 适配，但部分设备表现可能略有差异
- Universal Binary（Intel Mac）未构建
- 数据迁移已自动处理（'light' → 'workspace-light'，'dark' → 'workspace-dark'）
