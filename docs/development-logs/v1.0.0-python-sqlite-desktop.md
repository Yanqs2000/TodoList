# v1.0.0 — Python SQLite 桌面架构（2026-07-16）

## 版本定位

v1.0.0 是 TodoList 的首个稳定架构版本。应用仍然无需账号和云服务，但生产数据不再保存在浏览器 `localStorage`，而是由随桌面程序分发的 Python 后端统一写入本机 SQLite。

## 主要变更

### Python + SQLite 后端

- 新增 Python 3.12、FastAPI、Pydantic 和标准库 `sqlite3` 后端，使用 `uv` 管理环境。
- 提供任务 CRUD、排序、设置、成就、bootstrap 和提醒 claim API。
- 使用编号 SQL migration 与 `PRAGMA user_version` 管理数据库结构。
- 任务完成与成就更新在同一事务中提交；提醒通过原子 claim 避免重复通知。

### Tauri 桌面集成

- Python 后端通过 PyInstaller 打包为 Tauri external binary，用户无需单独安装 Python。
- Rust 负责 sidecar 启动、健康检查、重试、运行监控和关闭。
- 后端只监听 `127.0.0.1`，每次启动使用随机端口和随机 Bearer token。
- sidecar 或数据库不可用时，前端显示阻断恢复页，不回退到内存或 `localStorage`。

### 前端数据流

- React 启动时通过 bootstrap 获取任务、设置和成就的完整数据库快照。
- 数据变更只有在后端成功后才更新前端状态。
- 主题、静音、快捷键、成就和提醒去重状态全部迁入 SQLite。
- 普通浏览器模式不提供第二套数据层，只提示通过桌面应用运行。

### 中英文界面

- 首页右上角新增 `EN` / `中文` 按钮，可在中文和英文之间切换。
- 导航、任务操作、弹窗、设置、主题、成就、确认框、通知、错误、无障碍标签及日期日历均使用同一套类型化词典。
- 英文日期和星期使用 `en-US` 本地化；中文界面保持原有文案与显示样式。
- 用户输入的任务标题与备注不翻译，切换语言时保持原文。
- 语言选择通过 SQLite `app_settings.language` 持久化，写入成功后界面才切换；重新启动应用会恢复上次选择。

### 项目结构与文档

- 代码拆分为 `frontend/`、`backend/` 和 `desktop/`。
- 文档按前端、后端、运行架构和历史日志分类。
- 补充 API、SQLite、后端开发、运行架构及 macOS 构建说明。

## 升级说明

v0.5.0 及更早版本保存在 `localStorage` 的数据不会自动迁入 SQLite。首次运行 v1.0.0 会创建新的 `todo.sqlite3`，按全新安装开始使用。

当前发布包面向 macOS arm64，使用 ad-hoc 签名且未启用 hardened runtime/notarization。这样可以让 PyInstaller one-file sidecar 正常加载其运行时解压的 Python 动态库。首次打开时可能需要在 Finder 中右键选择“打开”；详见 [安装与构建说明](../architecture/installation.md)。
