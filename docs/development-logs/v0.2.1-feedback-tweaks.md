# v0.2.1 — 用户反馈调整 + Code Review 修复（2026-06-18）

## 概览

基于实际使用反馈对 v0.2.0 的小幅修订，并完成第二轮 code review 的全部修复。

## v0.2.1 用户反馈调整

### 1. 主题系统：editor → mint
- 删除 `editor-light` / `editor-dark`
- 新增 `mint-light` / `mint-dark`：浅绿底（#F0FDFA）/ 深绿底（#0A1F1C），accent 仍为 teal
- legacy `editor-*` localStorage 自动迁移为 `mint-*`

### 2. 默认 filter
- 从 `'all'` → `'active'`，进入界面默认显示进行中任务

### 3. 移除导入/导出
- 删除 Header 顶栏的导入/导出按钮
- 删除 `useTodos.exportTasks` / `useTodos.importTasks`
- 删除 file input、`handleImport`、`handleFileChange`
- `validateTodoArray` 仍保留（被 `loadInitialTasks` 使用以校验 localStorage）

### 4. 清除已完成反馈
- `useTodos.clearCompleted()` 改为返回 `cleared: number`
- App 根据返回值显示 toast：`已清除 N 个已完成任务`

## CSS 主题架构（v0.2.1 优化后）

```css
:root {
  /* 全局共享：radius, transition, --category-work（teal/blue 浅深通用） */
}
[data-theme$="-light"] {
  /* 浅色共享：primary, cta, priority-*, category-*, completed-opacity */
}
[data-theme$="-dark"] {
  /* 深色共享：primary, danger, shadow-*, completed-opacity */
}
[data-theme="workspace-light"] { /* 仅差异 token：bg, text, border, ... */ }
```

每个主题文件只定义"与同模式其他主题不同"的 token，约 12 个变量。
