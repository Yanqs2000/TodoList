# v0.3.1 — 时间编辑增强（2026-06-19）

## 概览

两项小改动，让时间设置更顺手：
1. 任务创建后可在详情面板修改时间
2. 时间选择器默认填充当前系统时间（之前固定为 09:00）

## 变更

### 1. 详情面板支持修改时间

`DetailPanel` 时间区域新增「修改时间 / 设置时间」按钮：
- 任务无时间：按钮文字为「设置时间」
- 任务有时间：按钮文字为「修改时间」，可重新调度
- 点击后内嵌展开 TimePicker（与 CreateTaskModal 一致的体验）
- 修改后保存，配合 `useReminders` 的 `id|time.start` 复合键，会触发新提醒

### 2. TimePicker 默认时间为当前系统时间

`parseDateTime` 拆分为 `parseStart` / `parseEnd`：
- `parseStart` 在没有传入 time 时，默认填充**当前系统时间**（年月日时分）
- `parseEnd` 保持原行为：默认结束时间为开始日期的 18:00（合理默认值）

之前的行为：默认日期是今天但时间硬编码 09:00，凌晨用户也得手动改时间，反人类。
