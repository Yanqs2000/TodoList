# v1.3.0 — Agent 记忆系统与 SSE 实时流式传输

日期：2026-07-25

分支：`dev-agent`

---

## 版本概览

v1.3.0 基于 v1.2 的 LangGraph 多节点架构（analyze → plan → execute → reflect），系统性修复了会话记忆缺陷、新增 SSE 实时流式传输、优化前端交互体验，并修正了模型能力认知偏差。

---

## 核心变更

### 1. 会话记忆系统修复

**问题**：同一次会话中，模型完全不记得前面的提问。根因分析发现四处缺陷：

| 缺陷 | 位置 | 修复 |
|---|---|---|
| 查询路径无对话历史 | `turn_graph.py:_execute_read` | 注入 `_build_ark_messages` 完整对话历史 |
| `analyze()` 截断到 5 条 | `planning.py:analyze` | 扩大到 10 条消息 |
| `turn_memory` 无语义价值 | `turn_graph.py:_reflect` | 新增 `user_question`、`assistant_summary` 字段 |
| 助手回复无语义 | `turn_graph.py:_proposal_message` | 改为 "已生成 3 项提议：新建「买菜」；修改「团队会议」" |

**结果**：模型现在可以通过双通道获取上下文——对话历史（`_build_ark_messages` 注入）提供自然对话流，结构化记忆（`turn_memory`）提供跨轮语义摘要。

### 2. SSE 实时流式传输

**架构**：

```
前端 fetch(ReadableStream) ←SSE→ 后端 StreamingResponse ←queue→ LangGraph Turn (on_event)
```

**事件流**：

```
event: step → {text: "正在理解你的需求..."}
event: analysis → {text: "用户想修改旅游任务...", intent: "mutations"}
event: step → {text: "生成计划：修改「去旅游」"}
event: plan → {evidence: "...", items_count: 1}
event: step → {text: "自检通过"}
event: reflect → {ok: true, text: "已生成 1 项操作"}
event: done → {message, proposalBatches}
```

**关键文件**：

| 文件 | 变更 |
|---|---|
| `turn_graph.py` | 新增 `EventCallback` + `_emit()` + 5 个节点事件发射 |
| `assistant.py` | 新增 `send_message_stream()` — `asyncio.Queue` + `run_in_executor` 桥接 |
| `assistant_api.py` | 新增 `POST /messages/stream` SSE 端点 |
| `client.ts` | `fetch` + `ReadableStream` SSE 解析 |
| `useAssistant.ts` | 流式优先 + 降级回退 + `streamingStep` 状态 |
| `MessageList.tsx` | 实时思考步骤指示器 |

**错误恢复**：
- 120 秒超时自动 fail turn
- 客户端断连检测 (`STREAM_DISCONNECTED`)
- `ArkUnavailableError` 和 `Exception` 均调用 `_fail_turn()` 清理状态

### 3. 前端交互优化

| 功能 | 变更 |
|---|---|
| 助手按钮 | 点击切换（打开/收起），与其他图标按钮一致 |
| 今日摘要 | 新增柱状图按钮，与助手按钮相同的推入动画切换 |
| 任务详情 | 与今日摘要合并布局——摘要卡片始终显示，任务详情在下部展开 |
| 任务选择 | 点击切换（再次点击取消），切换到其他任务自动更新详情 |
| Enter 发送 | Enter 发送消息，Shift+Enter 换行 |
| 助手图标 | SVG 图标替换文本字符（＋⚙✕ → 匹配界面尺寸） |
| X → 减号 | 助手面板 X 改为减号图标，功能改为删除当前会话 |
| 消息发送 | 乐观即时显示用户消息，再显示"正在思考…"指示器 |
| EN 按钮 | 高度/圆角与其他图标按钮对齐 |

### 4. Prompt 能力清单修正

**问题**：模型显示"当前系统仅支持新增待办，无法直接修改已存在任务的时间"——`Capability boundary: supports only...` 让模型误以为自己只能创建不能修改。

**修复**：`ANALYZE_PROMPT` 和 `_PLANNER_SYSTEM_PROMPT` 改用正面清单：

```
YOU CAN DO ALL OF THESE:
- CREATE a new task
- UPDATE an existing task's text, time, priority, category, or notes
- DELETE an existing task
YOU CANNOT: mark as completed, set location, add participants, set reminders
```

## 架构演进（v1.2 → v1.3）

```
v1.2                               v1.3
────                               ────
analyze_intent                     analyze_intent (+ emit events)
  → query | clarify | mutations      → SSE: analysis {reasoning, intent}
plan_intent                        plan_intent (+ emit events)
  → query | mutation                 → SSE: plan {evidence, items}
resolve → build → verify           resolve → build → verify
reflect                            reflect (+ emit events)
  → ok | repair | error              → SSE: reflect {ok, text}
persist → finalize                 persist → finalize (+ emit done)
                                   + on_event callback pipeline
                                   + asyncio.Queue bridge
                                   + 120s timeout + disconnect detection
                                   + turn_memory {user_question, assistant_summary}
                                   + execute_read conversation history
                                   + _proposal_message task details
```
