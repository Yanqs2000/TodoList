# v0.1.6 — macOS DMG 签名修复（2026-06-17）

## 问题

用户反馈：在别人 Mac 上安装 `.dmg` 后，提示"应用程序已损坏，无法打开"。

## 根因

经诊断，构建产物有 4 个问题：

| # | 问题 | 诊断结果 |
|---|---|---|
| 1 | DMG 完全未签名 | `code object is not signed at all` |
| 2 | .app 是 ad-hoc 签名（无 Team ID） | `Signature=adhoc, TeamIdentifier=not set` |
| 3 | 只构建了 arm64 架构 | `Mach-O 64-bit executable arm64`，仅装了 `aarch64-apple-darwin` target |
| 4 | DMG 内部结构无签名链 | adhoc app 套未签名 dmg |

macOS Gatekeeper 对未签名/未公证应用会加 `com.apple.quarantine` 隔离属性，导致显示"已损坏"。

## 修复

### 1. tauri.conf.json 显式配置 ad-hoc 签名

```json
"bundle": {
  "macOS": {
    "signingIdentity": "-",
    "minimumSystemVersion": "11.0",
    "entitlements": null
  }
}
```

- `signingIdentity: "-"` 表示 ad-hoc 签名（无需 Apple Developer 证书）
- `minimumSystemVersion: "11.0"` 明确最低系统要求

### 2. 新增 DMG 后签名脚本

`scripts/sign-macos-bundle.sh`：

- 对 `.app` 做 `codesign --force --deep --sign - --options runtime --timestamp=none`
  - `--deep`：递归签名所有辅助文件
  - `--options runtime`：启用 hardened runtime（公证的前置要求）
- 对 `.dmg` 做 `codesign --force --sign - --timestamp=none`

### 3. 新增 npm scripts

```json
"tauri:build": "tauri build && bash scripts/sign-macos-bundle.sh",
"sign:macos": "bash scripts/sign-macos-bundle.sh"
```

`npm run tauri:build` 一步完成构建 + 签名。

### 4. 用户安装说明

新增 `docs/installation-guide.md`，包含：

- 三种首次打开方式（右键打开 / xattr 命令 / 系统设置允许）
- 常见问题排查（"已损坏" / "无法验证开发者" / Intel Mac 不支持 / DMG 打不开 / 启动闪退）

README 同步更新，桌面端构建章节加签名说明 + 链接到 INSTALL.md。

## 不在本轮修复

### Intel Mac 支持（Universal Binary）

需要安装 `x86_64-apple-darwin` target 并重新构建，构建时间会变长。本轮先解决"已损坏"问题。后续单独做 Universal Binary。

### Apple Developer ID 正式签名 + 公证

需要付费 Apple Developer Program（$99/年）。若用户提供证书身份，可加配置：

```json
"macOS": {
  "signingIdentity": "Developer ID Application: Your Name (XXXXXXXXXX)",
  "entitlements": "entitlements.plist"
}
```

并配合 `xcrun notarytool submit` 做公证。这是商业级方案，无需用户绕过 Gatekeeper。

## 验证

签名后产物状态：

```bash
$ codesign -dv --verbose=2 "Todo List.app"
Identifier=app-cd754fac4cedcfd5
Format=app bundle with Mach-O thin (arm64)
CodeDirectory v=20400 size=64120 flags=0x20002(adhoc,linker-signed) ...
Signature=adhoc

$ codesign -dv --verbose=2 "Todo List_0.1.5_aarch64.dmg"
Identifier=...
Format=disk image
Signature=adhoc
```

用户安装流程（一次绕过）：

```bash
xattr -dr com.apple.quarantine /Applications/Todo\ List.app
```

之后双击即可正常启动。
