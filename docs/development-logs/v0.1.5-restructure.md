# v0.1.5 — 项目结构重组（2026-06-17）

## 概述

在前一轮 bug 修复（v0.1.4）基础上，对项目进行专业的结构与文档重组，提升可维护性。

## 代码结构重组

### 旧结构（扁平）
```
src/
├── App.tsx
├── main.tsx
├── components/        # 14 个组件平铺
├── hooks/             # 5 个 hooks 平铺
├── styles/            # 16 个 CSS 文件平铺
├── utils/             # 工具函数
├── constants.ts
├── types.ts
└── test/
```

### 新结构（feature-based）
```
src/
├── app/                          # 应用入口
│   ├── App.tsx
│   ├── main.tsx
│   └── styles/App.css
├── features/                     # 按业务功能划分
│   ├── tasks/                    # 任务管理
│   │   ├── components/           # TaskInput, TaskList, TaskItem, ...
│   │   ├── hooks/                # useTodos, useDragDrop
│   │   ├── lib/                  # validateTodo, id
│   │   └── styles/
│   ├── achievements/             # 成就系统
│   ├── theme/                    # 主题切换
│   ├── sound/                    # 音效
│   ├── confetti/                 # 撒花动画
│   ├── feedback/                 # 通用反馈（InfoToast）
│   ├── header/                   # 顶部栏
│   └── stats/                    # 底部统计
├── shared/                       # 跨功能共享
│   ├── lib/storage.ts
│   ├── constants.ts
│   └── types.ts
├── test/
└── vite-env.d.ts
```

### 路径别名

新增 `@/*` → `src/*` 别名（tsconfig.json + vite.config.ts + vitest.config.ts），所有 cross-feature import 改用绝对路径，摆脱相对路径深度困扰。

```typescript
// 旧
import { useTodos } from './hooks/useTodos';
import { safeSetItem } from '../utils/storage';

// 新
import { useTodos } from '@/features/tasks/hooks/useTodos';
import { safeSetItem } from '@/shared/lib/storage';
```

### CSS 就近放置
每个 feature 的 CSS 移到 `features/<name>/styles/`，与组件同目录层级，不再全部堆在 `src/styles/`。

## 文档重组

### 旧结构
- `README.md` — 项目介绍（停留在 v0.1.3）
- `doc/development-log.md` — 单文件全版本日志（与 `docs/` 拼写不一致）
- `docs/compose/plans/` — 3 个 brainstorming plan
- `docs/superpowers/plans/, specs/` — 2 个 brainstorming 文件
- `docs/2026-06-17-code-review-bugfix.md` — 散落的修复记录
- `docs/testing-guide.md` — 测试指南

### 新结构
```
docs/
├── project-overview.md           # 当前项目介绍（与 README 同步）
└── development-logs/
    ├── v0.1.0-initial.md
    ├── v0.1.1-ime-fix.md
    ├── v0.1.2-time-picker.md
    ├── v0.1.3-categories.md
    ├── v0.1.3-testing-guide.md
    ├── v0.1.4-code-review-bugfix.md
    └── v0.1.5-restructure.md     # 本文件
```

- 删除 5 个 brainstorming 历史（git 历史保留）
- 合并 `doc/` → `docs/`
- 按版本拆分开发日志，每版一个文件
- README 与 `docs/project-overview.md` 内容同步
