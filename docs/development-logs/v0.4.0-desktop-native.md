# v0.4.0 — 桌面原生体验（2026-06-19）

## 概览

v0.4.0 让 Tauri 桌面端真正像一个 macOS 原生应用：系统托盘、关闭即隐藏、全局热键唤起快速添加、开机自启动、设置面板。

## 新增功能

### 🍎 系统托盘
- 启动后菜单栏出现 Todo List 图标
- 左键点击图标：切换主窗口显示/隐藏
- 右键点击图标：弹出菜单
  - **显示窗口**：把主窗口前置
  - **新建任务**：唤起主窗口并打开创建任务模态
  - **退出**：完全退出应用
- 图标使用 `icon_as_template`，自动适配亮/暗系统主题

### 👋 关闭即隐藏到托盘
- 点击主窗口的关闭按钮（或 Cmd+W）→ 隐藏窗口，应用继续在托盘运行
- 通过托盘菜单或全局热键可重新唤起
- 行为对齐 Things / Bear 等专业 macOS 应用

### ⌨️ 全局热键快速添加
- 默认 `Alt+Space`，在任意应用下按出 → 唤起主窗口并打开创建任务模态
- **可在「设置」面板中自定义**：点击快捷键按钮 → 按下新组合 → 应用
- 持久化到 localStorage (`todo-shortcut`)，下次启动自动恢复
- 后端通过 `tauri-plugin-global-shortcut` 实现

### 🚀 开机自启动
- 在「设置」中开启后，登录系统时自动启动应用（最小化到托盘）
- 通过 `tauri-plugin-autostart` 的 LaunchAgent 模式实现
- 用户可随时关闭

### ⚙️ 设置面板
- Header 顶栏新增齿轮图标，打开桌面设置 popover
- 包含：全局快捷键录制、开机自启开关
- Web 版本下设置项被禁用并显示提示

## 实现架构

### Rust 端（src-tauri/src/lib.rs）
```rust
- 引入插件: notification + autostart + global-shortcut
- 启用 tauri "tray-icon" feature
- TrayIconBuilder: 创建带菜单的托盘图标
- on_window_event(CloseRequested): 拦截关闭，改为 hide
- 注册 #[tauri::command] quick_add / show_window / set_global_shortcut
- 全局热键 handler: emit "open-create-modal" 事件
```

### 前端端
```
src/features/desktop/
├── hooks/useDesktop.ts          # Tauri 事件桥接 + 热键 / 自启 API
├── components/SettingsModal.tsx # 设置面板 (热键录制 + 自启开关)
└── styles/SettingsModal.css
```

- `useDesktop` 检测 `__TAURI_INTERNALS__` 全局，区分桌面 / Web 环境
- 监听 `open-create-modal` 事件 → 触发 `setCreateModalOpen(true)`
- 提供 `setShortcut()` 调 Rust 命令 + 持久化
- 提供 `toggleAutostart()` 调插件 enable / disable
- 设置面板组件支持键盘录制热键（按下组合自动转换为 Tauri accelerator 字符串）

## 权限配置

`src-tauri/capabilities/default.json` 新增：
- `core:window:allow-show / hide / set-focus / unminimize`
- `core:event:allow-listen / unlisten`
- `global-shortcut:allow-register / unregister / unregister-all / is-registered`
- `autostart:allow-enable / disable / is-enabled`
- `notification:default`

## 不在本轮的事项

### 通知行动按钮（推迟到 v0.4.1+）
Tauri 2 的 notification 插件官方 API 不支持带 actions（"标记完成"/"推迟"）的通知。要做需自定义封装 NSUserNotification（macOS）/ Windows Toast Action，跨平台一致性差。先做基础三件套，actions 留待后续。
