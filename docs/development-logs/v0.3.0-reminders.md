# v0.3.0 — 时间提醒功能 + mint 主题淡雅化（2026-06-18）

## 概览

新增任务时间提醒功能（Notification + 5s 音效 + Toast），同时调整 mint 主题：浅色降饱和度，深色去除绿色改为中性深灰。

## 新增功能

### ⏰ 时间提醒
- 任务到达 `time.start` 时自动提醒（每 30s tick 检查）
- 三重反馈：
  - 系统通知（首次有定时任务时请求权限）
  - 5 秒柔和钟声音效（C5 + E5 双音 × 5 次，1s 间隔）
  - InfoToast：`⏰ 任务到时间了：{任务名}`
- 已触发的任务持久化到 localStorage（`todo-reminded` key），避免重启后重复提醒
- 跳过过期 24 小时以上的任务（避免应用启动时 spam 旧任务）
- 用户重新设置时间后会再次提醒（通过 `id|time.start` 复合键追踪）

### 实现细节
- 新增 `src/features/reminders/hooks/useReminders.ts`
- 新增 `useSound.playReminder()` — 5s 双音钟声
- App 在 `allTasks` 有定时任务时按需请求 Notification 权限
- 7 个单元测试覆盖：触发、跳过完成态/无时间/未来时间、跨重启去重、过期跳过、重新调度

## 主题调整

### mint-light：淡雅薄荷
- 饱和度大幅降低，从浅绿 `#F0FDFA` 改为近白 `#F7FAF9`
- 文字从 `#134E4A` 改为更通用的 `#2D3F3C`
- border 从 teal-100 改为偏灰的 `#DCE7E4`

### mint-dark：去除绿色
- 从 `#0A1F1C` 深绿底改为中性深灰 `#1A1D1C`
- 卡片 `#13302C` → `#25292B`
- 文字色调中性化，不再带绿色色相
