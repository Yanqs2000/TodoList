# v0.1.3 — 任务分类、备注、搜索、导入导出（2026-06-14）

## 新功能

### ✏️ 任务编辑
点击任务文本或铅笔图标进入编辑模式，回车保存，Esc 取消。

### 🏷️ 任务分类
预定义四类：工作 / 学习 / 生活 / 其他。支持按分类过滤。

### 📝 任务备注
任务可附备注，展开/收起查看。

### 🔍 搜索功能
按文本、分类、备注全文搜索。

### 📦 导出 / 导入
JSON 格式备份与恢复：
- 导出：`todo-backup-YYYY-MM-DD.json`，含版本号与时间戳
- 导入：按 id 去重，跳过已存在的任务

## Bug 修复

1. `Category` 类型移除 `| string` 联合类型，恢复枚举严格性
2. 移除 `TaskItem` 中多余的 `escapeHtml` 调用（React JSX 自带转义，双重转义导致显示异常）
3. `AudioContext` 添加 `resume()` 调用，修复浏览器自动播放策略导致的无声
4. `localStorage.setItem` 添加 try/catch，防止隐私模式或配额满时崩溃
5. 移除 `useAchievements` 中的死代码
6. 清除已完成操作添加确认对话框
7. `CATEGORY_LABELS` 提取到共享 `constants.ts`
