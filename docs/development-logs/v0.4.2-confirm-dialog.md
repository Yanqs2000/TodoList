# v0.4.2 — 修复清除已完成/删除按钮无效（2026-06-19）

## 问题

用户反馈「清除已完成」按钮点击后无任何反应（无效）。经排查，根因是 **`window.confirm` 在 Tauri WebView 下不可靠**：

- 同步 `window.confirm` / `window.alert` / `window.prompt` 在部分 WebView 宿主下被静默拦截，返回假值
- 在 jsdom 测试环境下默认返回 `false`
- 结果：`if (window.confirm(...))` 永远为假 → `onClearCompleted()` 永不执行 → 按钮看着"无效"

同样的 bug 也影响删除任务（TaskItem 删除、DetailPanel 删除）—— 共 3 处使用 `window.confirm`。

## 修复

用一个应用内的确认对话框替换全部 `window.confirm`，在 Web 和 Tauri 下都可靠。

### 新增 `ConfirmProvider` + `useConfirm()` hook

`src/shared/components/ConfirmDialog.tsx`：

```tsx
const confirm = useConfirm();  // (opts) => Promise<boolean>

const ok = await confirm({
  title: '清除已完成任务',
  message: `确定要清除 ${n} 个已完成的任务吗？此操作不可撤销。`,
  confirmText: '清除',
  danger: true,          // 红色确认按钮
});
if (ok) onClearCompleted();
```

特性：
- 命令式 API，返回 Promise<boolean>
- 通过 React Context 注入，任意深层组件可调 `useConfirm()`
- Portal 渲染到 document.body
- Esc 取消、点遮罩取消、Enter 确认（确认按钮 autofocus）
- 支持自定义 `title` / `message` / `confirmText` / `cancelText` / `danger`
- 风格与现有 modal 一致（圆角、阴影、动画、reduced-motion 适配）

### 替换 3 处调用点

| 文件 | 操作 |
|---|---|
| `Footer.tsx` | 清除已完成 → `confirm({ danger: true })` |
| `TaskItem.tsx` | 删除任务 → `confirm({ danger: true })` |
| `DetailPanel.tsx` | 删除任务 → `confirm({ danger: true })` |

所有 handler 改为 `async`，onClick 接受 async handler。

### main.tsx 包裹 ConfirmProvider

```tsx
<ConfirmProvider>
  <App />
</ConfirmProvider>
```
